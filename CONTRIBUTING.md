# CONTRIBUTING

## Add a Language Track

Create a new folder under `/languages` for language-specific concept templates and a matching folder under `/backend` when backend examples are needed for that language.

## Add a Concept File

Create the concept file in the correct track folder and follow the nearest `_template.md` structure exactly.

## LeetCode Links

Verify that every LeetCode link exists and matches the concept pattern before submitting the concept file.

## Manual Link Verification

LeetCode and SD links must be manually verified before any PR is merged. No auto-generated or AI-hallucinated links allowed — broken links are worse than no links.

## Complete Five Lenses

Every new concept file must have all five lenses filled before submission; partial submissions are not accepted.

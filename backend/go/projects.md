# Go Backend Projects

This file defines placeholder project checkpoints for each learner level.

## Beginner Project
Build a simple REST API with one endpoint — no DB, in-memory only.
Concepts practiced: http-servers, basic routing, JSON responses

## Intermediate Project  
Build a URL shortener with PostgreSQL — CRUD + SQL.
Concepts practiced: databases, auth, REST design

## Expert Project
Build a job queue system with workers, retries, and a status endpoint.
Concepts practiced: concurrency, queues, system design in code

## Rules

- Each project must use only concepts taught up to that point.
- Project file gets pushed to `languages/go/projects/` folder when built.
- Claude assigns project based on `mode` field in `profile.md` automatically.
